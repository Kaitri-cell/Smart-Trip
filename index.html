Smart Trip Budget Planner

An Analysis and Design of Algorithms (AOA) Academic Showcase

Problem Statement

Modern travel planning involves multi-dimensional combinatorial optimization constraints: budget limits, pairwise transit distances, activity durations, and group experience preferences. This project bridges theoretical computer science with real-world travel software by genuinely implementing fundamental algorithms to solve exact optimization subproblems.

Algorithms Implemented

  • 0/1 Knapsack (DP): Activity selection under budget limit
  • Dijkstra (Min-Heap): Single-source shortest paths
  • Floyd-Warshall: All-pairs shortest path matrix
  • TSP Branch & Bound: Exact multi-stop itinerary ordering
  • Greedy Strategies: Transport selection & heuristics

Data Structures Utilized

  • Binary Min-Heap: Logarithmic priority queue operations
  • Adjacency List: Memory-efficient weighted graph representation
  • 2D DP Matrices: Dynamic programming tables & snapshots
  • Sets & Maps: O(1) state lookups and visited tracking
  • State-Space Trees: Branch & bound pruning search

Built with Vanilla JavaScript, HTML5, CSS3, SVG, and HTML5 Canvas. Zero external runtime dependencies.
